拷问记录：游玩+看番经历

阶段 1：入坑前（2019.6 之前）

  • [x] 初三之前玩过什么游戏？

    初三之前我主要玩部落冲突和皇室战争，然后黄色战争在高中之后也有玩越来越少。

  • [x] 崩坏3 入坑的契机？

    入坑崩坏三应该是看了一八年圣诞的剧情应该是希儿感觉很喜欢。

  • [x] 超炮→B站→二次元的路径？

    一开始看超炮和魔禁的时间不太记得，但一开始是把B站当作视频平台看的，因为B站的名字来源于超炮，所以就看了。

阶段 2：日本行+高一上（2019.6-2020.1）

  • [x] 崩坏3 入坑时机？日本 ACG 体验？

    其实崩坏三在入坑之前已经云了很久了，在日本旅行的时候也有在一边看。但是第一次去日本的时候，我还不是很了解ACG相关的东西，去了挺多地方，那个时候记得很多京都动画里面的场景，后来发现原来那些地方去过。

  • [x] 高一开学后游戏节奏？竞赛冲突？

    高一开学之后平时会用手提电脑趁电脑课、竞赛集训，还有其他空闲时间来玩，在周末的时候有手机了就用手机来玩。跟竞赛关系主要是竞赛作为一个持有手提电脑和去机房的理由，让我在一些自由时间可以玩游戏。

  • [x] 明日方舟 2019 开服知道吗？

    应该是不太知道。

  • [x] 19年5月确定去向后到开学前在干什么？

    19年5月左右是高中提前招生，大概五月下旬就已经确定了去向，然后就开始玩崩坏三，开始准备高中八月开始的竞赛集训，然后提前组好了高中住的房，之后就是一直很喜欢崩坏三一开始是用手机玩的，后来因为我在学校有一台自己的手提电脑，但没有手机，所以经常趁空闲到竞赛集训机房里面去玩崩坏三。

阶段 3：疫情线上学期（2020.2-2020.7）

  • [x] 方舟 2.7 入坑契机？

    入坑原因可能是因为年的活动，看到后来就入坑了。

  • [x] 原神 1.0 上线前关注？

    原神上线前有关注但不太多。高中时期实际上时间没有很多，课余时间基本上都在做竞赛和补习，而且那个时候玩崩坏三也不碰深渊也不追版本。

  • [x] 疫情居家的 ACG 生活？

    大约是2020年上半年疫情开始居家的时候开始厨一些声优唱见，看过一个绀海组唱lemon的mmd非常喜欢。

阶段 4：高二上+长沙（2020.9-2021.1）

  • [x] 长沙之行性质？

    长沙行是竞赛培训，那段时间应该不怎么玩游戏。

  • [x] CSP2020 翻车？

    CSP2020 T1我没翻车，我是NOIP T3比较严重，详见退役记。

  • [x] 足球在生活中的分量？

    高中基本上学校的草坪只要没有在维护，我都有去踢足球，但是学校草坪维护还是维护了挺长时间的。高一入学的时候，我还保持灵巧的风格，后来好像某一次脚踝伤了，可能又加上疫情期间不怎么锻炼机动性下滑了，后来开始踢门将。我高中生活还是挺丰富的，基本上有什么就玩什么，像什么羽毛球乒乓球校运会各种活动我都有参加，而且我们班是特殊情况管理非常宽松。上课，尤其是数学课，还有晚自习班里实际上人非常少，是一种非常特殊的氛围。

  • [x] 还玩过什么别的游戏？

    好像还在什么时候玩过王者荣耀和东方project。高中期间还玩Minecraft和不少同学一起玩很开心。

  • [x] 二次元文化接触的入口？

    高中阶段实际上开始接触二次元文化，可能跟洛谷有关系。

阶段 5：高二寒假+退役+高考（2021.1-2021.6）

  • [x] 原神入坑契机（1.29 海灯节）？

    后来应该是在NOI冬令营期间压力比较大，而且高中的时候不怎么会管理自己的时间，自然的从崩坏三里面看到原神，然后去玩发现非常好，尤其是音乐。

  • [x] 三开时间分配？

    这段时间时间分配好像没什么印象，原神因为版本内容不多，基本上都是能玩完，崩坏三和明日方舟主要是追主线做一些日常。

  • [x] OI退役后的感受？

    考完冬令营之后，我知道自己肯定没有机会进省队了，那一个寒假应该是什么都没做，就在家里玩游戏，想起来还是挺平静的。当然后来我发现高中阶段的竞赛学习其实挺混乱的，没有形成什么好的知识体系。OI退役是因为冬令营考得太差了，考场上没有分配好自己每道题的预期管理。

  • [x] 退役到高考游戏曲线？

    我退役之后我就开始备考少创和高考了，精神上比较紧张，玩游戏次数可能变少了一些，但大概到五月因为明日方舟周年庆又回坑了一下之后，在高考前后又开始玩一些游戏。

  • [x] 崩坏3 兔女郎事件+支配剧场/薪炎永燃？

    崩坏三在二一年初遭遇了一场舆论危机，叫做兔女郎事件。当时看见自己热爱的故事和人物在网上被人辱骂，然后看到有大量退坑销号事件的发生还是觉得挺难过的。崩坏三的这两个剧情大概基于这些事件给了我一些启发吧，情感渲染到很到位。也给我冲刺高考带来一些动力。

  • [x] 原神 1.3-1.6 印象？

    原神因为早期剧情其实并没有很多，所以基本上版本感知不强。要说的话，可能是海岛的版本玩得比较开心。同样因为原神也一直有舆论事件，我这段时间大概也一直在思考这个游戏的优缺点，例如在1.5若陀龙王的故事里面。同时入坑原神之后我大概也开始捡起小提琴，开始在B站上看拿弓子的波塞冬，看了不少原神音乐分析和复刻，这是我第二次音乐启蒙。

  • [x] 早期最喜欢的剧情？

    那个时候很喜欢明日方舟的乌萨斯的孩子们的剧情，后来又翻出来看；同时崩坏三大部分我都非常喜欢。

阶段 6：高考后暑假（2021.7-2021.8）

  • [x] 高考后游戏安排？

    高考后的暑假实际上因为和同学们的安排不同，所以并没有安排出去玩，可能也有疫情的原因。那段时间在学英语，后来又在培训机构里当助教做了一些分享，然后空闲时间学了一些日语。7月12日左右听了一个数学相关的课程，但是基本上只听懂了一半，后来分心了。

  • [x] 暑假游戏和稻妻？

    同时还可能在玩明日方舟两个号，而且还加了一个国际服的新号；去玩了崩坏学园二。稻妻很好玩，一直在玩，应该是从版本开始就一直玩。

  • [x] 薪炎永燃反应？

    薪炎永燃动画短片看完之后觉得非常感动，非常振奋。当时写了一篇关于自己竞赛生涯的退役记来发泄情感。

  • [x] 原神入坑前有没有观望期？

    原神上线那段时间我可能在暑假的时候跟一个学长学习了一段时间，受到这个的影响，我又捡起竞赛了，然后稍微冲刺的一段时间。

阶段 7：大一上（2021.9-2022.1）

  • [x] 大学习惯变化？

    大一开学之后，基本上每个游戏还是在追版本的。新社交圈当时不太适应，和室友有很多观念冲突，然后也参与了很多活动，上课和剧情可能不太平衡。

  • [x] 明日方舟为什么停了？

    明日方舟似乎是因为二一年暑假有一些舆论事件没有继续玩，其实我并不了解舆论事件。

  • [x] 其他游戏？

    21年10月21日，我还玩了未定事件簿。

阶段 8：大一寒假+大一下（2022.1-2022.7）

  • [x] 层岩巨渊体验？

    那段时间包括层岩巨渊和渊下宫都是刚更新三到五天内就探索度百分百了，然后没事做就喜欢在原神里面逛街。

  • [x] 方舟什么时候回坑？

    明日方舟应该是在过年的时候回坑。

阶段 9：告别中大+大二上（2022.8-2023.1）

  • [x] 告别中大和京吹的关联？

    实际上在中大只是去临时做科研，做了两个星期，我确实很喜欢这个地方，但是跟京吹没有关系。看完京吹之后我应该挺长一段时间没有继续看番，因为受到震撼，实际上太大了。

  • [x] 回科大后的状态？

    回到科大的时候，基本上还沉浸在京吹的世界里面，大概是开始吹次中音号了。

  • [x] 无期迷途？

    游戏应该是正常打，然后后来无期迷途开服的时候玩了一段时间。

  • [x] 大二上崩3退坑+须弥+看番？

    大二上一方面，我开始听古典音乐开始看番，另一方面，学业压力确实非常大；须弥的内容也很好，但是内容量太大了，一下就玩不过来了；22年8月之后，因为疫情封校呆在宿舍的时间变多了，经常一两天就看完一部番。这段时间学不太懂，数学压力比较大。

阶段 10：大二寒假+大二下（2023.1-2023.7）

  • [x] 崩铁+1999 入坑？

    崩铁是一直非常期待；1999是临入坑才发现的。但两个游戏我都非常喜欢。但是1999早期的sidestory比较拖沓质量不太行，所以我基本上只追了主线。

  • [x] 这学期成绩和精神状态？

    这学期的成绩是我四年最差的一个学期。当时觉得近世代数学着还行，复分析快要挂科了，复分析一般般。结果复分析挂科了，另外两门也刚刚合格。实分析一方面学不懂，另外一方面期末时有一位助教突然没了，对我震撼非常大。实际上整一个大二包括上下两半学期还有寒假，我的精神状态都不是很好，这段时间发生的事情极其需要被好好整理一下。

阶段 11：大三上+FES（2023.8-2024.1）

  • [x] 23年7月发生了什么？

    23年7月发生了不少事。当时还没考完试就去找了一会老师想要做NLP方面的科研，后来不了了之。去讲了一个关于巴洛克音乐的讲座，大概从大二开始我就担任一些乐团里面的工作。

  • [x] 上海 FES？

    后来在学校一直待到八月去上海参加了表姐的婚礼，然后在上海到处逛，快要回家的时候，妈妈说拿到了fes的票，然后我一个人去了。

  • [x] 10-12月看番+游戏？

    10到12月，因为课程突然变轻松了，而且作息还没调整回来经常半夜看完一番或者通宵看完一次sidestory。

阶段 12：大三寒假+大三下（2024.1-2024.7）

  • [x] 原神退坑原因？

    大三下在计划最后的保研冲刺。那个学期压力偏大，但不来自深度学习，深度学习非常简单。可能没有特别的退坑原因和设备课程作息可能都有关系。

  • [x] MyGO+邦多利入坑因果？

    先看MyGO再入坑的邦多利。

  • [x] 图形学奇迹月？

    学是指上课上了几节之后发现强度非常大，但是错过了退课时间可能跟那个学期一开始的时候由于智齿发炎发烧了有关系就错过了时间，而且那个学期整个学期没有怎么做学的作业而作业占70%的总分，所以后来在考前两周疯狂做完了工程量非常大的准备学期的作业，然后还花三天刷了一个深度学习比赛。

阶段 13：大四上+ICPC（2024.8-2025.1）

  • [x] 纳塔回坑感受？

    大版本回坑是照例回坑，听音乐看新剧情。音乐挺好的，但是不如璃月稻妻的时候那样震撼可能是那段时间一方面在看番和推galgame，另一方面，感到那些长篇作品断了太长时间没玩。

  • [x] 凉宫春日？

    那段时间是第一次看凉宫春日。我当时发现凉宫春日这个人充满了想象力和创造力，而我感到自己在大学期间跟以前中学时期的自己割裂，可能是因为大二大三期间的经历。想要找回中学时期有创造力有激情的自己，所以春日这部分的想象力对我有很大的冲击。

阶段 14：毕业季+暑假（2025.1-2025.8）

  • [x] PJSK 入坑原因？

    最主要还是25:00的吸引力。

  • [x] 乐队番路径？

    这些都是当时比较火的乐队番，所以就都看了一下，我比较喜欢mujica。

  • [x] 25上半年游戏出勤几乎全零？

    二五年上半年应该还在打音游，但确实出于一些原因，长线剧情的游戏我都有点断掉，我也想弄明白是具体是什么原因。

阶段 15：研一上至今（2025.9-2026.5）

  • [x] 方舟 2026.4 回坑？

    因为乌萨斯的孩子们活动"人们，我们"，还有周年庆，但其实除了"人们，我们"，至今还没有静下心来看后续剧情。

  • [x] 京吹三期评分 7/10？

    第三季制作有所下滑，导致表达力不够，而这也引发了一些社区舆论。

  • [x] 终将 9/10？看番偏好转向？

    看番偏好没有太大的改变。

  • [x] 现在的游戏状态？

    现在玩游戏都比较少。一部分原因可能是换了设备之前的游戏不太经常用了，但是过年期间我还玩了挺长时间终末地。现在我打算至少捡回一些游戏。否则话题有点少。
