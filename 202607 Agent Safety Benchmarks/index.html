Anthropic

  • 【2025-03-13】【Anthropic】【官方研究博客】Auditing language models for hidden objectives：Anthropic 将 alignment audit 具体化为实验流程：故意训练带隐藏目标的模型，再让审计团队盲查；是后续 AuditBench 和自动化审计 agent 的方法学前置工作。

  • 【2025-07-24】【Anthropic】【Alignment Science Blog】Building and evaluating alignment auditing agents：提出并评估自动化 alignment auditing agents，让 agent 自主使用工具审计目标模型；关键意义是把“审计 agent 本身是否有效”变成可测对象。

  • 【2025-11-26】【Anthropic】【官方工程博客】Effective harnesses for long-running agents：讨论长时程 agent 的评测 harness 工程，包括跨 session 状态、初始化脚本、进度文件、端到端验证；核心观点是 harness 质量会显著影响 agent eval 可信度。

  • 【2026-03-10】【Anthropic】【Alignment Science Blog】AuditBench：发布 AuditBench，包含 56 个植入隐藏行为的模型，用于评估 auditor agent 是否能发现 hidden behaviors；是 2026 年最关键的 alignment auditing benchmark 之一。

Others

  • 【2026-04-11】【McGill University / Kean University / Zayed University】【arXiv 预印本】Taxonomy and Consistency Analysis of Safety Benchmarks for AI Agents：对 2023–2026 年 40 个智能体安全基准进行六维分类学和一致性分析，指出当前评估方法存在指标割裂、覆盖深度不足和排名不一致问题。

现在新的 agent safety 工作大致测 8 类东西：

  1. 有害任务执行能力 / 拒绝能力：AgentHarm、Agent-SafetyBench、HarmBench、XSTest。
  2. 工具调用安全：SafeToolBench、TS-Bench、MT-AgentRisk、SafeAudit、AgentCanary。
  3. 提示注入 / 环境注入 / 供应链注入：AgentDojo、InjecAgent、ASB、SkillInject、SABER、WASP。
  4. 长轨迹 / 多轮 / 延迟触发风险：ATBench、HINTBench、SODA、MT-AgentRisk、NRT-Bench。
  5. 真实可执行环境 / 状态持久化环境：SABER、AgentCanary、Risky-Bench、NRT-Bench、α³-Bench。
  6. coding agent 安全：SusVibes、SABER，以及 SusVibes 对比的 BaxBench、CWEval、SALLM、SecCodePLT、Asleep、ASE、SecureAgentBench。SusVibes 明确指出旧代码安全基准多是单文件/单函数或单轮生成，而其自身做 repository-level、多文件、agent 执行环境评估。
  7. 审计器 / guardrail / judge 能力：AgentAuditor/ASSEBench、AgentDoG/ATBench、TS-Guard/ToolSafe、HINTBench、SafeAudit。
  8. benchmark 元分析 / 一致性审计：Taxonomy and Consistency Analysis、SafeAudit。Taxonomy 论文梳理 2023–2026 的 40 个行为型 agent safety benchmarks，并指出不同 benchmark 的 threat model、metric、environment fidelity 会导致模型安全排名不一致。

SABER 这篇很适合看“新工作到底拿什么当 baseline”：它显式横向比较了 XSTest、HarmBench、AgentHarm、PrivacyLens、SafeToolBench、InjecAgent、AgentDyn、NAAMSE、SkillInject，并指出这些既有 benchmark 对 full project environment、embedded injection、risky self-selection、contextual warnings 覆盖不足。

  • 【2025-07-03】【FAIR at Meta + UC Berkeley】【arXiv 预印本】Meta SecAlign: A Secure Foundation LLM Against Prompt Injection Attacks 摘要：把 prompt-injection robustness 训练进基础模型，释放 Meta-SecAlign-8B/70B；属于模型层 guardrail，与 Meta FAIR 和 UC Berkeley 顶级安全研究组强相关。

System Securiy Conference

  • 【2025-08】【UC Berkeley / Berkeley Security / David Wagner 组】【USENIX Security 2025】StruQ: Defending Against Prompt Injection with Structured Queries 摘要：用 structured queries 将 trusted prompt 与 untrusted data 分成不同通道，并训练模型只服从 prompt 通道；是“指令-数据隔离”路线的代表论文，另有 Berkeley BAIR 博客。

  • 【2025-08】【Fudan University + UC Davis / Hao Chen 组】【USENIX Security 2025】Make Agent Defeat Agent: Automatic Detection of Taint-Style Vulnerabilities in LLM-based Agents 摘要：提出 AgentFuzz，用 directed greybox fuzzing 自动发现 LLM agent 的 taint-style 漏洞；更适合做发布前安全测试、CI gate 和 agent app 安全回归测试。

  • 【2025-08】【Ben-Gurion University of the Negev】【USENIX Security 2025】Cloak, Honey, Trap: Proactive Defenses Against LLM Agents 摘要：用 deception、honeypot、trap agents 对抗恶意 LLM agents，保护 CTF/网络资产；属于主动欺骗式防御路线，不依赖单纯 prompt injection 检测。

  • 【2025-09-09】【ShanghaiTech University + Independent Researchers】【CCS 2025】AgentSentinel: An End-to-End and Real-Time Security Defense Framework for Computer-Use Agents 摘要：面向 computer-use agents 的端到端实时防御框架，拦截敏感操作并结合任务上下文与系统 trace 做审计；非常贴近“sensitive operation → audit → allow/kill”的审批架构。

  • 【2025-10-13】【Meta FAIR + UC Berkeley / Berkeley Security】【CCS 2025】SecAlign: Defending Against Prompt Injection with Preference Optimization 摘要：把 prompt injection defense 表述为 preference optimization，让模型偏好服从真实任务而非注入指令；与 Meta FAIR 和 UC Berkeley 明确相关，是模型层 prompt-injection defense 的核心路线之一。

  • 【2025-11-18】【Fudan University】【ASE 2025】Security Debt in LLM Agent Applications: A Measurement Study of Vulnerabilities and Mitigation Trade-offs 摘要：对 221 个真实 agent 漏洞做测量，归纳 14 类漏洞、15 个根因和 7 个组件层面问题；适合作为 guard / approval / agent platform 安全设计的工程风险清单。

  • 【2026-01-11】【Mohamed bin Zayed University of Artificial Intelligence】【USENIX Security 2026】Overcoming the Retrieval Barrier: Indirect Prompt Injection in the Wild for LLM Systems 摘要：研究如何让间接提示注入内容更容易被 RAG/agent 检索命中，说明生成端 guard 不够，检索层也需要污染检测、来源审计和内容审批。

  • 【2026-03-01】【EPFL / Scala LAMP / Martin Odersky 组】【ACM CAIS 2026】Securing Agents With Tracked Capabilities 摘要：用 Scala 3 capture checking 和 tracked capabilities 让 agent 以 capability-safe code 表达工具调用意图，把权限、资源访问和信息流约束前移到类型系统；对 coding agent 与工具调用安全非常关键。

  • 【2026-04-15】【National University of Singapore + USC + SonarSource】【ICSE 2026 SEIP】Fixing Security Vulnerabilities with Agentic AI in OSS-Fuzz 摘要：把 agentic repair 用于 OSS-Fuzz 漏洞修复，通过 exploit execution 和 static typing 信息增强补丁生成；代表“自动修复 + maintainer approval”的落地路径。

  • 【2026-04-17】【Monash University + CSIRO Data61 + Columbia University + NYU】【ICSE 2026 Research Track】When AI Takes the Wheel: Security Analysis of Framework-Constrained Program Generation 摘要：以 Chrome extensions 为对象评估 LLM 生成完整框架约束程序的安全性，发现高比例漏洞；对 coding agent 的权限约束、安全扫描和合并前审批有直接参考价值。

  • 【2026-04】【Brown University / Brown Systems / Malte Schwarzkopf 组】【EuroMLSys 2026 Workshop】Towards Practically-Secure Tools for AI Agents 摘要：提出面向 agent tools 的安全框架：静态 effect synopsis、细粒度 sandbox、policy enforcement；最贴近 MCP/tool-use 场景下的 guard 架构升级。

  • 【2026-08】【Fudan University + Shanghai Innovation Institute】【USENIX Security 2026】Autonomy Comes with Costs: Detecting Denial-of-Service Vulnerabilities Caused by Resource Abusing in LLM-based Agents 摘要：提出 AgentDoS，用 directed greybox fuzzing 检测 LLM agents 因资源生命周期管理缺陷导致的 DoS 漏洞；提示 agent guard 不仅要防数据泄漏，也要管资源预算、循环、下载、文件和进程生命周期。
